# sales-skills-marketplace

## 설치
```
/plugin marketplace add <깃허브아이디>/<저장소명>
/plugin install weekly-sales-report@sales-skills-marketplace
```

## 포함된 플러그인
- **weekly-sales-report**: 판매관리 시트("판매내역")로 주간 매출 리포트를 만들어 슬랙에 전송합니다.

## 사용 전 준비
- Slack 커넥터를 연결해야 합니다.
- 판매관리 워크북(업로드 파일 또는 Google Sheets, 시트명 "판매내역")이 필요합니다.
- 전송할 슬랙 채널은 실행할 때 지정합니다(저장소에는 채널명이 들어 있지 않습니다).
