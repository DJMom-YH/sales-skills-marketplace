# 주간 매출 리포트 (Slack)

## 입력
- 판매관리 워크북(업로드 파일 또는 Google Sheets). 시트 "판매내역" 컬럼: 주문일, 주문번호, 판매채널, 카테고리, 상품명, 옵션, 수량, 판매단가, 결제금액, 배송비.
- 숫자는 "33,300"처럼 천 단위 쉼표가 있으므로 쉼표를 제거한 뒤 파싱한다.
- 업로드 파일명이 유니코드 정규화 때문에 경로로 안 열리면 `cd /mnt/user-data/uploads && f=$(ls | head -1)`로 접근하고, 작업 폴더(scratchpad)에 복사해서 쓴다.
- 파일은 "## Sheet name: 판매내역" ~ "## Sheet name: 대시보드" 사이가 행 데이터다. 날짜 범위(최소/최대)를 먼저 확인한다.
- 시각은 UTC가 아닌 한국 시간(KST)으로 표기한다.

## 집계 기준
- 기본 대상 주: 오늘 기준 가장 최근에 끝난 완전한 주(월~일). 비교 대상은 그 직전 주.
- 해당 주 이후 데이터가 일부 있으면(미완성 주) 본문과 분리해 참고로만 한 줄 덧붙인다.
- 지표: 매출(결제금액 합), 주문 건수(주문번호 고유 수), 판매 수량, 객단가(매출/주문 건수), 전주 대비 증감률.
- 추가: 채널별 매출·비중, 카테고리별 매출(전주 비교), 상품 TOP 5, 요약 2~3줄.
- 계산은 코드로 실행해 검증하고 손으로 추정하지 않는다.

## 슬랙 전송 규칙
1. 채널에는 첫 줄만 보낸다: `[주간 매출 리포트] M/D(요일)~M/D(요일)` (예: `[주간 매출 리포트] 10/19(월)~10/25(일)`).
2. 리포트 본문은 그 메시지의 스레드(thread_ts)에 한 건의 댓글로 단다.
3. 보내기 전에 채널(slack_read_channel)에서 같은 첫 줄의 메시지가 이미 있는지 확인하고, 있으면 보내지 않고 사용자에게 알린다.
4. 채널 ID는 slack_search_channels로 확인한다(처음 요청 시 채널 이름이 없으면 사용자에게 묻는다). 채널을 사용자가 지정하지 않았다면 주제/설명을 확인하고 맞지 않으면 보내지 않고 알린다.
5. 위에 정해지지 않은 기준(대상 주 변경, 내용 구성 변경 등)이 생기면 만들기 전에 사용자에게 먼저 묻는다.
6. 삭제 도구가 없으므로 잘못 보낸 메시지는 지울 수 없다. 보내기 전에 기준을 확인한다.

## 스레드 본문 형식 (Slack markdown)
```
## 📊 주간 판매 리포트 (시작일 ~ 종료일)

**핵심 지표 (전주 대비)**  — 매출/주문 건수/판매 수량/객단가 표 (이번 주, 전주, 증감)
**채널별 매출** — 채널, 금액, 비중, 전주 금액
**카테고리별 매출** — 금액, 전주 대비 ↑/↓
**상품 TOP 5** — 순위, 상품명, 금액
**요약** — 증감 원인 2~3줄 + 미완성 주 참고 한 줄
_출처: 판매관리 시트 (판매내역)_
```

## 마무리
- 전송 후 메시지 링크와 핵심 수치 1~2줄만 사용자에게 알린다.
